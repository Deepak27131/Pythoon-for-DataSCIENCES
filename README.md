# Pythoon for Data Sciences

## About
This repository contains **Python, Data Science, and Machine Learning practice notebooks**.
It is created for learning Python from basics and gradually moving towards Machine Learning.

---

## What you will learn
- Python basics (list, dictionary, loops, functions, OOPS)
- File handling in Python
- Data analysis using Pandas & NumPy
- Machine Learning basics
- Real dataset practice (Titanic dataset)

---

## Contents
- Python basic notebooks
- Machine Learning notebooks
- Titanic survival prediction project
- CSV dataset for practice

---
